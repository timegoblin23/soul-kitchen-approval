# Soul Kitchen relaunch approval

Interactive copy and creative approval document for the Soul Kitchen relaunch campaign.

**Live page:** https://timegoblin23.github.io/soul-kitchen-approval/

## What it contains

- Five copy routes, reproduced from the supplied copy deck.
- Five finished 4:5 creatives in the brand book’s flavour palettes.
- 23 claim checks against Bella’s marketing notes and the brand book.
- Inline copy editing, comments, rewrite drafts, per-route and per-creative status.
- An overall sign-off with a stamped record and Markdown / JSON export.

## How saving works

Comments, edits, rewrites and the sign-off save in the reviewer’s browser using
`localStorage`. They persist on that device and survive a page reload, but they do
not sync between devices or people. Use **Export** to copy or download the record
and send it to the team.

There is no backend, so nothing entered on the page is transmitted anywhere.

## Design

Uses the Soul Kitchen brand book palette — Broth Green `#184121`, Electric Pea Green
`#76B043`, Golden Lentil `#FFFDE9` — plus the five flavour colours. Headlines use
Soul Soup Regular; body copy uses Roboto, the brand book’s digital fallback for
Alternate Gothic ATF.
