# Soul Kitchen relaunch approval

Live: **https://timegoblin23.github.io/soul-kitchen-approval/**

A short copy and creative approval proof sheet for the Soul Kitchen relaunch.

## What the page does

- Shows five finished 4:5 creatives, uncropped, each with an **Approve creative** tick and a full-size link.
- Shows five copy routes, each with **Approve copy** and a **Copy change** field.
- **Copy for WhatsApp** copies a short approval note — approved and not-approved items plus any copy changes — ready to paste into a WhatsApp message.
- Nothing is sent automatically. Ticks and changes save in the browser only.

## Design

Soul Kitchen brand palette: Broth Green `#184121`, Electric Pea Green `#76B043`, Golden Lentil `#FFFDE9`, plus the flavour colours. Headlines use Soul Soup Regular; body copy uses Roboto. Light and dark mode.
